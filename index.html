📖 How Metrics Are Calculated

Average Gradient ⓘ

Formula: (Elevation Change ÷ Distance) × 100

Example: 200m gain over 2km = (200 ÷ 2000) × 100 = 10% gradient

Max Gradient ⓘ

Calculated over: 100-meter rolling windows

Finds the steepest 100m section and caps at 40% (even the world's steepest roads rarely exceed 35-37%)

Difficulty Score ⓘ

Formula: (Gain^1.3 × Avg Gradient) ÷ 100

Scaled 0-100, where longer and steeper climbs score higher. Based on the Fiets climbing formula.

  • Easy: 0-30
  • Moderate: 30-60
  • Hard: 60+

Similarity Score ⓘ

Weighted by:

  • Elevation gain difference (40%)
  • Distance difference (30%)
  • Gradient difference (30%)

Matching criteria: Two climbs only match if they're within the tolerance thresholds you set above (default: 25% for gain/distance, 2% for gradient). Tighter tolerances = fewer, more precise matches.

Smoothing ⓘ

Method: Moving average filter

Averages elevation values across nearby points to reduce GPS noise (±2-5m is common). Higher values = smoother profiles but may hide real variations.

Gain Threshold ⓘ

Purpose: Prevent noise accumulation

Ignores elevation changes below this value (default 3m). Prevents GPS noise from inflating total elevation gain. Strava uses ~4m threshold.
